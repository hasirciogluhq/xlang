## 2.1 `unsafe` bloğu

`unsafe { ... }`, blok içindeki kodda **işaretlilik değiştiren örtük dönüşüme** (`ui → i` ve `i → ui`)
izin veren bir bloktur. Rust'taki gibi "ne yaptığımı biliyorum" işaretidir ama kapsamı dardır: şu an
yalnızca bu tek kuralı gevşetir. `unsafe` başka bir kontrolü kaldırmaz (dizi sınırı
kontrolü, `*T` kuralları değişmez); onlar için `--safety` ve `@unchecked fn` vardır.

**Örtük**, `as` yazmadan compiler'ın dönüşümü kendisinin yapması demektir. `local a: i32 = n` yazarsın,
compiler `n`'i `i32`'ye çevirir. **Açık** dönüşüm ise `n as i32` diye elle yazılandır; her yerde geçer.

| İşlem | `unsafe` dışında | `unsafe { }` içinde |
|-------|------------------|---------------------|
| `ui32 → i32` (örtük) | **hata** `E0601` | geçer (bit deseni aynı kalır) |
| `i32 → ui32` (örtük) | **hata** `E0601` | geçer (bit deseni aynı kalır; negatifler büyük sayı olur) |
| `ui8 → i32`, `i8 → ui32` (örtük, hedef daha geniş) | **hata** `E0601` | geçer |
| `ui32 → f64`, `ui8 → f32` (örtük; float işaretlidir) | **hata** `E0601` | geçer (`i → f` gibi `W0601` uyarısı yine çıkar) |
| `ui64 → i32`, `i64 → ui8` (örtük, hedef daha dar) | **hata** | **hata**: daralma `unsafe` ile de örtük olmaz, `as` gerekir |
| `ui32 as i32`, `i32 as ui32` (açık) | geçer | geçer |

```xlang
fn main() -> i32 {
    local n: ui32 = 7
    local a: i32 = n                 // HATA E0601: işaretlilik değişiyor, örtük olmaz
    local b: i32 = n as i32          // OK: açık dönüşüm her yerde geçer

    local c: i32 = 0
    unsafe {
        c = n                        // OK: unsafe içinde örtük
    }
    return b + c
}
```

```
error[E0601]: `ui32` değeri `i32`'ye örtük olarak dönüştürülemez
  --> app.xl:4
   |
 4 |     local a: i32 = n                 <======= ui32 -> i32: işaretlilik değişiyor
   |
detay:  Kaynak işaretsiz, hedef işaretli; 2147483648 ve üstü değerler hedefte negatif olur.
neden:  Sessiz işaret değişimi hata kaynağıdır; dönüşüm bilerek yapılmalı.
düzelt: `n as i32` yaz, ya da bilerek örtük istiyorsan ifadeyi `unsafe { ... }` içine al.
```

| Kural | Açıklama |
|-------|----------|
| Yazım | `unsafe { ... }`: statement bloğu, fonksiyon gövdesinde herhangi bir yerde |
| Kapsam | Yalnızca bloğun sözdizimsel içi; çağrılan fonksiyonlara geçmez |
| Gevşettiği tek şey | İşaretsiz ↔ işaretli (`ui ↔ i`, `ui → f`; float işaretli sayılır) örtük dönüşümü, aynı ya da daha geniş hedefe; iki yön aynı kuraldır |
| Gevşetmediği | daralma, `f → i`, `*T` dönüşümleri: hepsi `as` ister |
| Tanı | Dışarıda `E0601`; `unsafe` içinde dönüşüm sessizdir |
| Açık `as` | `unsafe` gerektirmez, her yerde geçer |
