xlang is a low-level systems language. Its compiler is written in C++ and uses LLVM for code generation. Its standard library is written in xlang.

This site is the only documentation source for the project. People and AI tools read the same pages.

## Sections

- **Language**: syntax, types, classes, defer, entry point and variadic functions.
- **Compiler**: installation, linking, packages, the runtime and known limitations.
- **Standard library**: strings, collections, random values and identifiers, event polling, HTTP and system call numbers.
